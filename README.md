# zenn.dev

babarot's articles on [Zenn](https://zenn.dev/babarot), deployed from `main` by Zenn's GitHub integration.

```sh
pnpm install
pnpm check     # validate articles/*.md
pnpm preview   # http://localhost:8010/
```

Articles are `articles/<slug>.md`; images are `images/<slug>/`. How the repository is run, for people and agents: [AGENTS.md](AGENTS.md).
